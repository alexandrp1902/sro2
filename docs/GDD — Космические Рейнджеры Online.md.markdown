# GDD — «Космические Рейнджеры Online»

**Версия:** 0.1  
**Жанр:** многопользовательская космическая action-RPG / sandbox  
**Платформы:** ПК-браузер, мобильный браузер  
**Ориентация мобильной версии:** вертикальная  
**Режим игры:** постоянный онлайн-мир, real-time  
**Камера:** вид сверху  
**Основное управление:** прямое управление кораблем

---

# 1. Концепция

«Космические Рейнджеры Online» — браузерная многопользовательская космическая RPG, построенная вокруг исследования звездных систем, сражений, заработка кредитов и постоянного улучшения собственного корабля.

По духу игра ориентируется на классические «Космические рейнджеры», но вместо пошагового режима весь игровой мир существует **в реальном времени**.

Одновременно внутри звездной системы могут находиться:

- игроки;
- NPC-корабли;
- торговцы;
- пираты;
- военные;
- нейтральные корабли;
- космические станции;
- астероиды;
- ресурсы;
- обломки кораблей;
- боевые события.

Все корабли перемещаются и сражаются одновременно.

Игрок непосредственно управляет своим кораблем.

Основной цикл игры:

**вылет с базы → исследование системы → PvE/PvP → добыча → задания → кредиты → улучшение корабля → переход в более опасные системы → более ценная добыча → новые корабли и оборудование.**

---

# 2. Основные принципы

## 2.1. Простое управление

Игрок должен иметь возможность начать играть практически сразу.

На ПК:

- WASD или стрелки — управление кораблем;
- клик по кораблю — выбор цели;
- клик по ресурсу или предмету — выбор предмета для подбора;
- Space — стрельба из основного оружия;
- цифровые клавиши — дополнительные системы и оружие.

На смартфоне:

- виртуальный стик в нижней левой части экрана;
- кнопка атаки в нижней правой части;
- тап по противнику — выбор цели;
- тап по ресурсу — подбор/захват ресурса;
- дополнительные кнопки способностей располагаются рядом с кнопкой атаки.

---

# 3. Формат игры

Игра не делится на традиционные короткие матчи.

Игрок входит в постоянную игровую вселенную.

Его корабль появляется:

- на домашней базе;
- либо в последней посещенной безопасной точке.

Игрок может свободно:

- летать;
- торговать;
- выполнять задания;
- атаковать NPC;
- атаковать других игроков в разрешенных зонах;
- собирать ресурсы;
- исследовать системы;
- путешествовать между системами.

---

# 4. Игровой мир

Вселенная состоит из множества звездных систем.

Каждая звездная система представляет собой отдельную большую игровую карту.

Пример:

```text
        [Врата A]



[Врата D]        ЗВЕЗДА        [Врата B]


          Планеты
         Станции
         Астероиды


        [Врата C]
```

Внутри системы находятся:

- звезда;
- планеты;
- станции;
- базы;
- астероидные поля;
- NPC;
- игроки;
- случайные события;
- ресурсы;
- обломки;
- межсистемные врата.

---

# 5. Межсистемные врата

Переходы между системами выполняются только через специальные гиперврата.

Они располагаются преимущественно около краев или углов карты.

Например:

- северо-запад;
- северо-восток;
- юго-запад;
- юго-восток.

Каждые врата связаны с конкретной соседней системой.

Игрок подлетает к вратам и выбирает:

**«Гиперпрыжок»**

После активации начинается короткая подготовка.

Базовое значение:

**3 секунды.**

После этого корабль покидает текущую систему и появляется около соответствующих врат другой системы.

---

# 6. Топливо

Топливо расходуется **только на гиперпрыжки между системами**.

При обычном передвижении внутри системы топливо не расходуется.

Количество топлива определяет максимальную дальность путешествия.

Например:

| Бак | Топливо |
|---|---:|
| Малый | 100 |
| Средний | 180 |
| Большой | 300 |
| Военный | 450 |

Стоимость прыжка зависит от расстояния между системами.

Например:

```text
Расход топлива = расстояние × коэффициент двигателя.
```

Таким образом, установка большого топливного бака позволяет совершать более длинные маршруты.

# 7. Управление кораблем

## ПК

Управление:

```text
W / ↑ — вперед
S / ↓ — торможение / движение назад
A / ← — поворот влево
D / → — поворот вправо
```

Альтернативный вариант управления может быть включен в настройках:

**WASD — движение относительно экрана.**

Выбор цели:

**ЛКМ по кораблю.**

После выбора вокруг цели появляется рамка.

Например:

```text
    ┌─────────┐
    │ ПИРАТ   │
    │ 750 HP  │
    └─────────┘
```

Space:

**атака выбранной цели.**

# 8. Мобильное управление

Экран используется вертикально.

Пример интерфейса:

```text
┌───────────────────┐
│ HP █████████      │
│ SH ███████        │
│                   │
│                   │
│       ВРАГ        │
│        ◉          │
│                   │
│        ▲          │
│      КОРАБЛЬ      │
│                   │
│                   │
│  ◯            🔥  │
│ СТИК        АТАКА │
└───────────────────┘
```

Слева снизу:

**виртуальный аналоговый стик.**

Справа снизу:

**большая кнопка атаки.**

Над кнопкой атаки могут находиться:

- ракета;
- ускорение;
- щит;
- специальная способность.

Тап по кораблю:

**выбор цели.**

Тап по ресурсу:

**выбор ресурса для захвата.**

---

# 9. Выбор цели

Любой корабль можно выбрать кликом или тапом.

После выбора игрок видит:

- имя;
- уровень;
- тип корабля;
- фракцию;
- состояние корпуса;
- состояние щита;
- расстояние.

Например:

```text
BLACK WOLF
Пират

Корпус: 72%
Щит: 34%

Расстояние: 420
```

Оружие стреляет в выбранную цель.

Если цель находится вне дальности оружия:

**атака невозможна.**

---

# 10. Радар

Корабль может видеть цели только внутри зоны действия радара.

Радар определяет:

- максимальную дистанцию обнаружения;
- качество идентификации цели.

Базовые типы:

| Радар | Радиус |
|---|---:|
| Гражданский | 1 000 |
| Улучшенный | 1 500 |
| Военный | 2 200 |
| Дальнего обнаружения | 3 000 |

За пределами радиуса радара корабли не отображаются либо отображаются как неизвестные сигналы.

---

# 11. Система корабля

Каждый корабль состоит из:

**корпуса + модулей.**

Корпус определяет:

- HP;
- размер;
- маневренность;
- уклонение;
- количество модулей;
- максимальный класс оборудования;
- грузовой отсек.

---

# 12. Классы корпусов

## Легкий корабль

Плюсы:

- высокая скорость;
- высокое уклонение;
- высокая маневренность.

Минусы:

- мало HP;
- слабые пушки;
- слабый щит.

Пример:

```text
HP: 1 000
Уклонение: 30%
Оружие: 2
Модули: 4
```

---

## Средний корабль

```text
HP: 2 500
Уклонение: 18%
Оружие: 3
Модули: 6
```

Универсальный класс.

---

## Тяжелый корабль

```text
HP: 6 000
Уклонение: 7%
Оружие: 4
Модули: 8
```

Большая огневая мощь, но низкая маневренность.

---

## Линкор

```text
HP: 12 000
Уклонение: 2%
Оружие: 6
Модули: 12
```

Очень большая цель.

Практически не уклоняется, но способен устанавливать самые мощные:

- пушки;
- генераторы;
- щиты;
- радары;
- двигатели.

# 14. Оружие

Каждое оружие имеет:

```text
Урон
Точность
Дальность
Скорострельность
Энергопотребление
Класс
```

Например:

### Импульсная пушка Mk1

```text

Точность: 75%
Дальность: 700
Перезарядка: 1 сек.
```

---

# 15. Шанс попадания

У каждого оружия существует базовый шанс попадания.

У каждого корпуса существует базовый шанс уклонения.

Базовая формула:

```text
Шанс попадания =
Точность оружия
− Уклонение цели
+ модификаторы.
```

Результат ограничивается:

```text
5% ≤ шанс попадания ≤ 95%
```

Пример.

Пушка:

```text
Точность = 80%
```

Легкий корабль:

```text
Уклонение = 30%
```

Получаем:

```text
80 − 30 = 50%
```

Шанс попадания:

**50%.**

---

Тяжелый корабль:

```text
Уклонение = 5%
```

Получаем:

```text
80 − 5 = 75%
```

Шанс попадания:

**75%.**

Таким образом, крупные корабли значительно легче поразить.

---

# 16. Модификатор дистанции

Оружие имеет оптимальную дальность.

До оптимальной дальности штраф отсутствует.

После нее точность постепенно уменьшается.

Пример:

```text
0–500 м     0%
500–700 м  -10%
700–900 м  -25%
```

У оружия существует абсолютная максимальная дальность, после которой выстрел невозможен.

---

# 17. Щиты

Энергетический щит принимает урон раньше корпуса.

Например:

```text
Щит: 1 000
Корпус: 2 000
```

Попадание наносит:

```text
300 урона.
```

Получаем:

```text
Щит: 700
Корпус: 2 000
```

Щит начинает автоматически восстанавливаться, если корабль несколько секунд не получает урон.

Например:

```text
Задержка регенерации: 5 сек.
```

---

# 18. Энергия

Часть модулей корабля использует энергию.

Генератор определяет максимальную доступную мощность.

Например:

```text
Генератор: 100 мощности
```

Установлено:

```text
Пушка              25
Пушка              25
Щит                 30
Радар               10
Двигатель           10
----------------------
Итого              100
```

Нельзя установить оборудование, которое превышает возможности генератора.

---

# 19. Двигатель

Двигатель влияет на:

- максимальную скорость;
- ускорение;
- поворот;
- скорость торможения.

Более тяжелые корпуса требуют более мощных двигателей.

# 21. Подбор предметов в космосе

После уничтожения NPC или объектов в пространстве могут появляться:

- детали;
- ресурсы;
- контейнеры;
- компоненты.

Предметы физически находятся на карте.

На ПК игрок нажимает на предмет мышью.

На смартфоне — делает тап.

Предмет становится выбранным.

Когда корабль оказывается внутри радиуса захвата:

```text
100–150 метров
```

тракторный луч автоматически перемещает предмет в грузовой отсек.

Если грузовой отсек заполнен, появляется сообщение:

**«Недостаточно места в трюме».**

# 24. Уничтожение игрока

Главный принцип:

**игрок не теряет прогресс из-за уничтожения корабля.**

Игрок НЕ теряет:

- корабль;
- оружие;
- модули;
- ресурсы;
- груз;
- кредиты;
- опыт.

После уничтожения появляется экран:

```text
КОРАБЛЬ УНИЧТОЖЕН

Возвращение на базу через:

00:30
```

Через **30 секунд** игрок появляется на своей домашней базе.

Корабль полностью восстановлен.

---

# 25. Защита после респауна

После появления игрок получает временную защиту.

Например:

**10 секунд.**

Она снимается раньше, если игрок:

- стреляет;
- использует боевую способность.

Это исключает убийство игроков непосредственно при появлении.

---

# 26. Базы

Базы являются основными безопасными точками.

На базе игрок может:

- покупать корабли;
- покупать оборудование;
- продавать ресурсы;
- получать задания;
- заправляться;
- менять модули;
- ремонтировать корабль;
- выбирать домашнюю базу.

Рядом с базой действует безопасная зона.

Внутри нее PvP запрещено.

# 28. Основная прогрессия

Игрок начинает с небольшого корабля.

Например:

### Стартовый рейнджер

```text
HP: 800
Щит: 300
Уклонение: 25%

1 × пушка
1 × двигатель
1 × радар
1 × щит
1 × бак
```

По мере игры игрок зарабатывает кредиты.

Сначала покупает:

- лучшую пушку;
- двигатель;
- щит;
- радар.

После накопления достаточного количества денег покупает новый корпус.

---

```text

        ↓

        ↓

        ↓

        ↓
```

- скорость;

Большой:

- дальность;

Основные типы:

# 32. Сила NPC

NPC имеют уровни.

Например:

```text
Пират Ур.1
Пират Ур.5
Пират Ур.12
Пират Ур.30
```

Чем опаснее система, тем выше:

- уровень NPC;
- награда;
- качество добычи.

---

# 33. Уровни опасности систем

Каждая система имеет рейтинг опасности.

Например:

```text
1 — безопасная
2 — низкая опасность
3 — средняя
4 — высокая
5 — экстремальная
```

В системах высокого уровня:

- сильнее NPC;
- лучше ресурсы;
- выше награды;
- выше вероятность редких модулей;
- больше PvP.

---

# 34. PvP

Игроки могут сражаться друг с другом.

Предлагается разделить пространство на три типа.

### Безопасные системы

PvP выключено.

Используются новичками.

### Пограничные системы

PvP разрешено с ограничениями.

### Свободные системы

Полностью открытое PvP.

При этом игрок все равно ничего не теряет при уничтожении.

Следовательно, PvP остается соревновательным, но не наказывает игрока потерей недель прогресса.

# 49. Баланс большого и маленького корабля

Главный принцип:

**размер — одновременно преимущество и недостаток.**

Большой корабль:

```text
+ больше HP
+ больше щит
+ тяжелые пушки
+ больше модулей

- ниже скорость
- ниже уклонение
- легче попасть
```

Маленький:

```text
+ быстро летает
+ сложно попасть
+ высокая маневренность

- мало HP
- слабые пушки
- меньше модулей
```

Таким образом, линкор не гарантирует победу над группой хорошо управляемых легких кораблей.

# 66. Главная особенность игры

Ключевая идея проекта:

**это не пошаговая стратегия, а постоянно работающая многопользовательская версия игрового цикла «Космических рейнджеров», где игрок непосредственно управляет кораблем в реальном времени.**

При этом сохраняются основные ощущения:

- свободное путешествие;
- множество звездных систем;
- развитие корабля;
- торговля;
- пираты;
- задания;
- добыча;
- поиск хорошего оборудования;
- переход от маленького корабля к мощному боевому флоту.

Но игра изначально проектируется как:

**browser-first + mobile-first multiplayer game.**

Главный принцип прогресса:

> Игрок должен хотеть заработать еще немного кредитов, потому что следующая пушка, двигатель или новый корабль заметно изменят его возможности.

Главный принцип PvP:

> Проигрыш должен создавать желание взять реванш, а не желание закрыть игру.

Поэтому уничтожение корабля приводит только к **30-секундному респауну**, без потери денег, предметов или корабля.

Главный принцип боя:

> Чем тяжелее и мощнее корабль — тем проще в него попасть.

Это естественным образом создает разные игровые роли и не позволяет тяжелым кораблям полностью вытеснить легкие.
