# M3 — ядро боя: чек-лист плейтеста

Цель этапа — дуэль ПК против iPhone. Главные вопросы:
- даёт ли сектор стрельбы ±60° интересный манёвр;
- сколько длится бой (TTK);
- видно ли, где промах.

## Как запустить

- ПК + iPhone по Wi-Fi: `tools\dev.ps1` → http://localhost:5173 и `http://<IP-ПК>:5173`.
- Через интернет: сборка + сервер + `tools\tunnel.ps1` (см. README).
- Одному: две вкладки на ПК в **разных окнах** или бой с дронами слева от станции.

## Что нового

- **Цель.** Клик или тап по кораблю. Пальцу хватает попасть рядом: радиус выбора не меньше 36 px. Тап мимо кораблей цель не сбрасывает; снять её — ✕ на карточке или Esc. Tab — следующая цель по удалённости.
- **Атака.** Space или кнопка «ОГОНЬ» справа внизу. Пока держишь, пушка стреляет сама по готовности. Кольцо вокруг кнопки — перезарядка. Атака без цели сама берёт ближайший корабль: сначала в секторе, потом просто в дальности.
- **Сектор.** Пока есть цель, у корабля виден сектор ±60° до предельной дальности, дуга внутри — оптимальная дальность. Зелёный — стреляем, голубой — нет.
- **Шанс:** точность пушки − уклонение цели − штраф за дальность, в пределах 5–95%. Уклонение растёт со скоростью цели: остановившийся лёгкий — лёгкая мишень.
- **Карточка цели:** ник, корпус, полоски «Корпус» и «Щит», дистанция, шанс и состояние («в секторе» / «вне сектора» / «далеко» / «под защитой» / «уничтожен»).
- **Урон.** Щит принимает урон раньше корпуса и восстанавливается через 5 с без попаданий. Над каждым кораблём тонкие полоски корпуса и щита.
- **Эффекты.**
  - Трассеры: импульсная — снаряд, лазер — луч, плазма — медленный шар. Промах пролетает мимо цели.
  - Числа урона: синие — по щиту, оранжевые — по корпусу, «промах» — серым.
- **Уничтожение.** Взрыв, экран «КОРАБЛЬ УНИЧТОЖЕН» с таймером (10 с), потом корабль появляется у станции целым. В ленте — «A уничтожает B».
- **Защита после появления — 10 с,** вокруг корабля голубой пузырь. Пока она действует, по кораблю не стреляют. Свой выстрел снимает её сразу.
- **Дроны:**
  - «Учебный дрон» стоит слева от спауна;
  - «Дрон-мишень» кружит на полном ходу.

  Не стреляют, после уничтожения появляются снова.
- **Dev-панель:** кнопки пушек (Импульсная, Лазер, Плазма) и строка «огонь: выстрелов · попаданий (%) · ожидали %».

## Проверки

- [ ] Тап по кораблю на iPhone выбирает его с первого раза, в том числе на ходу и одновременно со стиком.
- [ ] Кнопка «ОГОНЬ» работает, пока держишь стик другим пальцем.
- [ ] Атака без цели берёт ближайший корабль.
- [ ] Чтобы стрелять, приходится доворачивать нос. Дуэль превращается в манёвр, а не в стояние на месте.
- [ ] На границе сектора состояние «в секторе / вне сектора» не мигает раздражающе.
- [ ] Промахи видны: снаряд уходит мимо, «промах» над целью. Фактический процент в dev-панели близок к «ожидали».
- [ ] Щит тает раньше корпуса, после паузы 5 с восстанавливается.
- [ ] Взрыв и экран уничтожения читаются. После респауна корабль стоит у станции, стик в центре, огня нет.
- [ ] Пузырь защиты виден. Выстрел его снимает.
- [ ] Кружащий дрон на полном ходу — заметно труднее, чем стоящий.
- [ ] Обрыв связи в бою: корабль без связи тормозит, не стреляет, по нему можно попасть; при возврате огонь не включается сам.
- [ ] Лаг 200 мс в dev-панели: огонь по-прежнему ощущается отзывчиво.
- [ ] Смена пушки и корпуса в dev-панели сразу меняет темп огня и живучесть.

## TTK

Время боя пишет лог сервера при каждом уничтожении: `… destroyed by …: TTK 12.3 s, shots 30, hits 13 (43%), expected 42%`. TTK считается от первого попадания до уничтожения.

| Цель ↓ / пушка → | Импульсная | Лазер | Плазма |
|---|---:|---:|---:|
| Лёгкий на ходу | | | |
| Лёгкий стоит | | | |
| Средний | | | |
| Тяжёлый | | | |

Ориентир по формуле для лёгкого на полном ходу: импульсная ≈ 13 с, лазер ≈ 12 с, плазма ≈ 15 с. Тяжёлый: 34 / 35 / 31 с.

## Что можно крутить (на лету, без перезапуска)

| Файл | Что |
|---|---|
| `shared/hulls.json` | `hp`, `shield`, `shieldRegen` (ед/с), `evasion` и `moveEvasion` (%) |
| `shared/weapons.json` | `damage`, `accuracy` (%), `cooldown` (с), `optimalRange`, `maxRange`, `rangePenalty` (%), `arc` (°) |
| `shared/combat.json` | `respawnSeconds`, `protectionSeconds`, `shieldRegenDelay`, `spawnJitter`, список дронов |

Невалидный файл сервер отклоняет целиком и пишет причину в лог; остаётся прежний баланс.
