# M22 — финал «Тихой войны», мастерская и развитие мехов

Состояние на 2026-10-11: код клиента и сервера реализован; добавлены и подключены отсутствовавшие P2/P3 и обязательные пустынные P4/P5. Комплект прошёл технический визуальный просмотр исходников и сборок. Четыре полных smoke-прогона после настройки финального гарнизона завершили финал за 9 / 13 / 13 / 15 раундов, в каждом прошли все 19 проверок. Ручной сквозной плейтест и проверка на физическом телефоне остаются открытыми; техническая проверка не заменяет их.

Ресурсы и калибровка описаны в [производственном отчёте](../../art/mechs/production/M22.md). Созданы 78 PNG-листов: 36 P2, 17 P3, 15 P4 и 10 P5, включая целый и разрушенный тягач. Четыре принятых P1 сохранены; все 36 игровых ключей теперь имеют собственные runtime-файлы.

## Обычный запуск

Из корня репозитория:

```powershell
npm --prefix client run build
dotnet run --project server/Sro.Server
```

Клиент и сервер используют протокол **38**. Перезапустить обе стороны. Для обычного прохождения переменная `SRO_STORY_SKIP` должна отсутствовать.

После сюжетного задания `prototype` прототип выдаётся один раз. На Нова-Прайм после космической части ретранслятор открывает «Первую вылазку». После первой победы появляются мастерская и бесплатные детали второй машины. Создать её и установить корпус, шасси, обе руки; затем выбрать двух собственных мехов для следующих операций. Союзные машины финала управляются сервером.

| Операция | Условие победы | Первая награда | XP цели выжившим |
| --- | --- | --- | --- |
| firstSortie | Уничтожить двух налётчиков | 1500 кр + комплект второй машины | 0 |
| mineDefense | Генератор жив после 6 полных раундов; волны 1/3/5 | 2000 кр + средний корпус и шасси, лёгкий щит, автопушка, бронемодуль | 25 |
| primeEscort | Тягач прошёл маршрут; занятую следующую клетку ждёт | 2500 кр + снайперский корпус и оружие, модуль точности | 35 |
| majorAssault | Собственный мех удерживает точку 2 полных раунда подряд без живого противника в зоне | 4000 кр + тяжёлый корпус и шасси, меч, тяжёлый щит, усилитель оружия | 50 |

Гибель собственных машин или защищаемого объекта имеет приоритет над победой. В финале уничтожение противников само по себе не завершает операцию. После поражения, отступления и победы повреждения ремонтируются бесплатно. Повторные победы дают XP, без повторной первой награды.

## Мастерская и баланс

До четырёх собственных мехов. Каждая деталь — отдельный экземпляр: нельзя поставить один экземпляр в две руки или на две машины. Изменение сборки и покупка применяются целиком после подтверждения сервера. Пустую сборку можно сохранить; для вылазки нужны корпус, шасси, обе руки и хотя бы одно оружие.

Масса — корпус + обе руки + рюкзак; масса шасси не добавляется. Лёгкое/среднее/тяжёлое двуногое шасси допускают 75/110/160, гусеницы — 150. Предпросмотр и каталог показывают массу после замены и перегруз.

| Каталог | Цена, кр |
| --- | --- |
| Корпуса light / medium / heavy / sniper | 600 / 900 / 1400 / 900 |
| Шасси lightBiped / mediumBiped / heavyBiped / tracked | 500 / 700 / 1000 / 900 |
| pistol-cannon / autocannon / shotgun / energy | 500 |
| sniper / sword / heavy-cannon / rockets | 850 / 700 / 1000 / 1000 |
| Щиты light / heavy | 400 / 900 |
| Каждый из пяти рюкзаков | 600 |

Все рецепты требуют 4 титана и 2 энергии; рецепты от 850 кр дополнительно требуют 1 редкий металл. Это начальная настройка в `shared/mechs.json`. Передача ресурсов между трюмом и личным складом — только в доке мастерской, с проверкой вместимости при возврате.

Примеры допустимых сборок из гарантированных деталей:

- Лёгкий снайпер: sniper + lightBiped + pistol-cannon слева + sniper справа, без рюкзака: 72/75. На среднем шасси помещается ещё модуль точности. При обороне точки снайпер стреляет с дистанции, второй мех удерживает зону.
- Тяжёлый мечник: heavy + heavyBiped + heavy shield + sword + damage backpack: 134/160.
- Две автопушки: medium + mediumBiped + autocannon в обеих руках. Обычная активация даёт один выстрел выбранной рукой.

XP хранится у машины, сохраняется при замене деталей. Порог следующего уровня: `100 + 75*(L-1) + 25*(L-1)^2`; уничтожение — базовые 50 с поправкой разницы уровней, победа — 25 выжившим плюс XP цели. На повышении возможен один новый совместимый навык, не более шести. Вероятности открытия и срабатывания интерфейс не показывает. Известный несовместимый навык сохраняется и отмечается неактивным в сборке.

Настройки после smoke:

- Числа оружия M21 и прицельный штраф 25 сохранены. Для первой сюжетной миссии введены два новобранца с пистолетными пушками и изношенным корпусом `bandit-worn` (700 HP, броня 10). При полном прежнем составе расширенный ИИ регулярно оставлял прототип без оружия.
- Позиции огня по генератору находятся в пяти клетках: снайперское оружие с минимальной дальностью 4 может участвовать в атаке объекта.
- Союзники финала получили тяжёлые шасси и корпуса; страж — тяжёлую пушку и усилитель, мечник — бронемодуль. Противники финала: щитоносец, рубака, снайпер и энергострелок. Штурмовик появляется в последней волне защиты шахты. В конфигурации есть вес угрозы вооружённого противника для ИИ.
- Бот использует бесплатные награды после 16 и 17 и разделяет роли снайпера и держателя точки. Ранняя версия без улучшений занимала 36–56 раундов. Для финала введены отдельные изношенные корпуса защитника (1200 HP, броня 15) и энергоносителя (900 HP, броня 10); старт игрока и союзников приближен к зоне. Эти варианты не меняют остальные миссии, оружие M21, число врагов или удержание точки два раунда.
- Четыре проверочных прогона после этой настройки: финал **9 / 13 / 13 / 15** раундов. Последний полный прогон: **10 / 6 / 8 / 15** раундов до победы. Поражения и повторные попытки первой вылазки, защиты и сопровождения сохраняются; smoke не доказывает победу с первой попытки или верхнюю границу для любого seed. Логи: `.artifacts/m22-art/smoke-final-{a,b,c,d}.log`. Ориентир 15 раундов сохранён; замер с ручной тактикой остаётся в приёмке.

## Сквозной smoke

Для воспроизводимого наземного прогона подготовить отдельный каталог. Он копирует обычный баланс и меняет только старт рейнджера на док Нова-Прайм; боевые числа и детали остаются обычными. Рабочие аккаунты не используются.

```powershell
python tools/mech-smoke-fixture.py
$env:SRO_STORY_SKIP='quietWar'
dotnet run --project server/Sro.Server --no-build -- --urls http://127.0.0.1:5057 --SharedDir C:/Users/467/Documents/GitHub/sro/.artifacts/m22-shared --DataDir C:/Users/467/Documents/GitHub/sro/.artifacts/m22-smoke-data
# В другом терминале:
node tools/smoke-mech.mjs ws://localhost:5057/ws
```

После отладки убрать `SRO_STORY_SKIP`. Обычный smoke без отдельного каталога также летит Сол → Вега → Нова, но космические пираты могут сорвать подготовку; наземный прогон изолирует этот фактор.

- [x] Все **19** проверок: первая победа и комплект, создание второй машины без покупок, четыре операции, конец кампании, повтор без выплаты, training, reconnect, другое устройство и вылет после итога.
- [x] Победы получены обычными запросами, без изменения HP противников или гарантии навыков. Неудачные попытки повторяются, их XP сохраняется по обычным правилам.
- [ ] Прохождение новым человеком 15–18 после обычной космической цепочки, без `SRO_STORY_SKIP`.
