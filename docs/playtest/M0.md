# M0 — каркас и доставка: чек-лист плейтеста

Цель этапа — убедиться, что игру можно открыть на ПК и iPhone по Wi-Fi и через интернет и что соединение живёт стабильно. Геймплея пока нет.

## Проверки

- [ ] ПК, http://localhost:5173: звёзды плавно плывут, статус «онлайн 1 · пинг N мс · 60 FPS».
- [ ] iPhone по Wi-Fi (`http://<IP-ПК>:5173`): на обоих устройствах «онлайн 2».
- [ ] iPhone: страница не зумится щипком или двойным тапом, не скроллится, нет «резинки».
- [ ] iPhone: свернуть Safari на 30 с и вернуться — переподключение за 1–2 с.
- [ ] Остановить сервер — статус «нет связи»; запустить снова — клиент переподключается сам.
- [ ] Tunnel: `https://<id>.trycloudflare.com` открывается на iPhone по мобильной сети (Wi-Fi выключен).
- [ ] GitHub Pages + `?server=<id>.trycloudflare.com`: подключается; после перезагрузки адрес помнится.
- [ ] Safari → «Поделиться» → «На экран Домой»: игра запускается без панелей браузера.
