# M4 — PvE, пираты: чек-лист плейтеста

Цель этапа — бой против 1–3 пиратов на телефоне. Главные вопросы:
- интересно ли;
- не слишком ли сложно;
- понятно ли, кто на тебя напал и куда от него уйти.

## Как запустить

- ПК + iPhone по Wi-Fi: `tools\dev.ps1` → http://localhost:5173 и `http://<IP-ПК>:5173`.
- Через интернет: сборка + сервер + `tools\tunnel.ps1` (см. README).
- После обновления перезапустите сервер, если он был запущен: версия протокола сменилась (4). Со старым сервером клиент пишет «сервер другой версии».

## Где пираты

У станции спаун. От неё до логов 12–20 с полёта на лёгком корпусе. На карте логова — красные круги с подписью состава.

| Логово | Где от станции | Состав | Сложность |
|---|---|---|---|
| Север | прямо вверх, 2100 | Пират Ур.1 | один на один — разминка |
| Юго-восток | вниз-вправо, 2700 | Пират Ур.1 | один на один |
| Запад | влево-вверх, 2600 | Пират Ур.2 ×2 | пара — уже бой |
| Северо-восток | вправо-вверх, 3400 | Тяжёлый пират Ур.3 + Пират Ур.2 | опасно |

## Что нового

- **Стрельба в любую сторону** (по просьбе после первого запуска): у всех пушек `arc: 180` в `weapons.json`. Разворачиваться к цели не нужно, вместо сектора у корабля — круг дальности. Вернуть сектор ±60° — `arc: 60`.
- **Цель за краем экрана** выбирается кликом или тапом по её стрелке у края или по подписи рядом.
- **Огонь — переключатель** (не надо держать): Space, кнопка «ОГОНЬ» или двойной клик / тап по цели включают, повторное нажатие выключает. Включённая кнопка горит красным и пульсирует, подпись «вкл»; на ПК под карточкой цели — «ОГОНЬ ПО ГОТОВНОСТИ» в красной рамке. Снятие цели и уничтожение своего корабля огонь выключают, уничтожение цели — нет: переключись на следующую, и стрельба продолжится.
- **Переключение целей:** на ПК Q / E, Shift+← / Shift+→, Shift+Tab / Tab — ближе / дальше по удалённости. На телефоне стрелки-шевроны `<` и `>` по бокам от «ОГОНЬ»; вся группа справа на высоте стика.
- **Выбранная цель за краем экрана:** её стрелка обведена оранжевым, подпись оранжевая.
- **Пираты** — красные корабли. В логове они медленно кружат. Замечают игрока ближе 700. Нападают и в ответ на выстрел, даже издалека: промах тоже считается. Пират рядом с атакованным собратом (до 900) вступает в бой.
- **«!» перед ником** — пират целится в вас. Стрелка к нему у края экрана крупнее. Под своими полосками — «под атакой: N».
- **Манера боя.** Пират кружит вокруг цели на своей дистанции: лёгкий около 320, тяжёлый около 420. Пара из одного логова кружит в разные стороны. От лёгкого пирата на лёгком корпусе не оторваться: он идёт следом и продолжает стрелять. Тяжёлый медленный — от него можно уйти. Если пушкам вернуть узкий сектор (`arc` < 90), пират снова будет разворачиваться носом к цели.
- **Укрытие** — пунктирный круг радиусом 900 вокруг станции. Пираты туда не залетают и бросают цель, которая в нём спряталась. Щит в укрытии восстанавливается через 5 с.
- **Отход.** У лёгкого пирата корпус упал до 25% — он перестаёт стрелять и летит в логово. Долетел — чинится полностью. Догоните и добейте. Тяжёлый не отступает.
- **Поводок.** Дальше 1800 от логова пират не гонится и возвращается домой, тоже с починкой. Возвращающийся пират ни на что не реагирует.
- **Уровни:** за каждый уровень выше первого +20% корпуса и щита, +10% урона, +2 к точности.
- **Респаун пирата** — 20 с, в своём логове.
- **Уничтожение пиратом:** в ленте «Пират Ур.1 уничтожает …», экран смерти как в M3.
- **Dev-панель** (Ё или тап по строке скорости): под ником пирата его состояние — «патруль», «атака», «домой».

## Проверки

- [ ] Логова видны на карте, до них понятно, как долететь. Стрелки у края экрана к пиратам не мешают.
- [ ] Пират Ур.1 один на один: игрок побеждает, но получает урон. Бой не скучный.
- [ ] Стрельба в любую сторону удобна: бой — это манёвр скоростью и дистанцией, а не разворот носом.
- [ ] Клик или тап по стрелке у края экрана выбирает этот корабль, по подписи — тоже.
- [ ] Огонь-переключатель удобнее удержания; по кнопке сразу видно, включён ли огонь.
- [ ] Двойной тап по кораблю включает огонь по нему, повторный — выключает; одиночный тап огонь не трогает.
- [ ] Кнопки `<` `>` и «ОГОНЬ» достаются большим пальцем и не мешают стику; Q / E и Shift+стрелки на ПК не поворачивают корабль.
- [ ] Пара Ур.2: бой напряжённый, но выигрываемый.
- [ ] Тяжёлый + эскорт: опасно, но от тяжёлого можно уйти скоростью.
- [ ] Кружащий пират — трудная, но не раздражающая цель.
- [ ] «!» и «под атакой» сразу показывают, кто напал. Нападение не приходит «из ниоткуда».
- [ ] Выстрел издалека поднимает пирата и его собрата.
- [ ] Раненый пират уходит в логово; догнать и добить можно. Упущенный возвращается целым.
- [ ] Бегство к станции работает: в укрытии пираты разворачиваются.
- [ ] Пираты не слипаются в одну точку и не дёргаются (смена «атака / домой» не мигает).
- [ ] На iPhone бой с 1–3 пиратами играется: стик + кнопка огня + выбор цели тапом.
- [ ] Атака без цели (Space / кнопка) берёт ближайшего пирата.
- [ ] Обрыв связи рядом с пиратом: корабль без связи пираты не трогают, после возврата бой продолжается.

## Ориентиры по формулам

Игрок — лёгкий корпус с импульсной пушкой, на ходу.

| Противник | Игрок убивает его | Он убивает игрока |
|---|---:|---:|
| Пират Ур.1 | ≈ 10 с | ≈ 29 с |
| Пара Ур.2 | ≈ 11 с на каждого | вдвоём ≈ 13 с |
| Тяжёлый Ур.3 | ≈ 24 с | ≈ 21 с |
| Тяжёлый Ур.3 + эскорт Ур.2 | — | ≈ 11 с |

Фактическое время пишет лог сервера при каждом уничтожении: `Пират Ур.1 (light) destroyed by … (pulse): TTK 9.8 s, shots …`. Там же видно, что делает ИИ: `Пират Ур.2 #7 attacks …`, `returns home: retreat`, `is back home and repaired`.

| Бой | TTK пирата | TTK игрока | Итог |
|---|---:|---:|---|
| Пират Ур.1 | | | |
| Пара Ур.2 | | | |
| Тяжёлый + эскорт | | | |

## Что можно крутить (на лету, без перезапуска)

Файл `shared/npcs.json`:

| Поле | Что |
|---|---|
| `types.*.hp`, `shield` | прочность и щит пирата 1-го уровня |
| `types.*.damage` | множитель урона его пушки (0.45 — меньше половины игрока) |
| `types.*.weapon`, `hull` | пушка и корпус из `weapons.json` / `hulls.json` |
| `types.*.holdRange` | на какой дистанции держится в бою |
| `types.*.retreatHp` | при какой доле корпуса уходит чиниться (0 — никогда) |
| `levelScaling` | прибавка за уровень: доли `hp`, `shield`, `damage`, пункты `accuracy` |
| `aggroRange`, `dropRange` | когда замечает и когда теряет цель |
| `assistRange` | из какого радиуса собрат приходит на помощь |
| `leashRange` | как далеко от логова гонится |
| `stationSafeRadius` | радиус укрытия |
| `patrolRadius`, `patrolThrottle` | патруль вокруг логова |
| `respawnSeconds` | респаун пиратов |
| `spawns` | логова: `type`, `level`, `x`, `y`, `count`. Смена списка пересоздаёт пиратов |

Правка параметров сохраняет доли корпуса и щита пирата. Логово нельзя поставить ближе, чем «укрытие + патруль + дальность самой дальнобойной пушки» (сейчас 1850): иначе пирата можно было бы бить из укрытия. Такой файл сервер отклоняет и пишет причину в лог.
