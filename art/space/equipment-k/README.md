# Пачка K — оружие, модули и мина для M19

Все 9 изображений созданы встроенным image_gen 2026-09-24 в стиле `equipment-extra`. Исходные PNG с альфа-каналом сохранены без изменений. Фактические размеры и проверка прозрачности — в `validation.json`.

Фактический размер каждого исходника — 1254×1254 (генератор выдал его вместо запрошенных 1024×1024). Проверка границ видимого объекта использует alpha ≥ 16: на прозрачных полях некоторых оригиналов есть почти невидимые пиксели с меньшей alpha, исходники не ретушировались.

Состав соответствует разделу «Арт (пачка K)» плана M18–M23: дробовик, гаусс-пушка, минный постановщик, ракетный залп; грузовой захват, сканер, маскировка, бронеплиты; мина строго сверху.

Откройте [preview.html](preview.html) для просмотра на светлом/тёмном фоне и в размерах 64, 96 и 256 px. Полные промпты — [prompts.md](prompts.md), файлы и происхождение — [manifest.json](manifest.json).

Это исходный арт: подключение в игровые каталоги не выполнялось. Целевой размер иконок при экспорте — до 256 px, мины — 96 px. Веер дробовика и трасса гаусса по плану рисуются кодом и в этот набор PNG не входят.
