# Космические изображения

Созданы встроенным imagegen. Исходные PNG с прозрачностью, 1254×1254, RGBA — в сборку игры не входят (22 МБ).

**Как попадают в игру.** `python tools/sprites.py` (нужны Pillow с WebP и numpy) нарезает листы в
`client/public/sprites/*.webp` (~2 МБ) и пишет размеры в `client/src/render/spriteMeta.json`. Результат лежит в git:
перезапускать только после замены листов. Корабли режутся на корпус и пламя (`…-flame`): пламя рисуется по тяге.

Где что используется: корабли — `render/ship.ts` (пиратский — у всех пиратов), станции и звёзды — `render/world.ts`,
планеты и далёкое солнце на фоне — `render/starfield.ts`, метеориты — `render/meteorView.ts`, ресурсы — лут
в космосе, трюм и док, пушки — витрина дока, выстрелы и взрывы — `render/combatFx.ts`.
Пока не используются: `minerals.png`, `modules.png` (модулей в игре ещё нет — M9), ракетница, «электроника».

| Файл | Содержимое | Сетка |
| --- | --- | --- |
| suns.png | Четыре солнца | 2×2 |
| planets.png | Четыре планеты | 2×2 |
| stations.png | Четыре станции | 2×2 |
| ships.png | Лёгкий, средний, тяжёлый и пиратский корабли, нос вверх | 2×2 |
| weapons.png | Импульсная пушка, лазер, плазма, ракетница | 2×2 |
| modules.png | Двигатель, щит, грузовой модуль, сканер | 2×2 |
| meteors.png | Девять разновидностей метеоритов | 3×3 |
| minerals.png | Девять разновидностей минералов | 3×3 |
| resources.png | Металл, руда, энергоблок, титан, кристаллы, редкий металл, плазменный компонент, контейнер, электроника | 3×3 |
| explosions.png | Девять стадий взрыва | 3×3 |
| weapon-shots.png | Эффекты трёх видов оружия | 3×3 |

В weapon-shots.png строки сверху вниз: импульсная пушка (жёлтый), лазер (голубой), плазма (фиолетовый). Столбцы слева направо: снаряд/луч, вспышка выстрела, попадание. Направление выстрела вправо. Точный запрос генерации: weapon-shots.prompt.txt.

Порядок объектов на остальных листах: слева направо, сверху вниз. Сетка описывает композицию; перед нарезкой следует проверить фактические границы объектов. Кадры взрыва требуют проверки выравнивания и темпа при сборке анимации.
