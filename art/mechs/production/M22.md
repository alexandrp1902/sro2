# Комплект M22 — 2026-10-11

Созданы 78 PNG-листов через встроенный imagegen: 36 компонентов P2, 17 листов P3, 15 обязательных листов пустынного окружения P4 и 10 состояний объектов P5. Последние включают целый и разрушенный тягач сопровождения. Четыре принятых компонента P1 сохранены. Все 36 игровых ключей имеют собственный арт; дополнительные пулемёты и экспериментальное оружие экспортированы для обеих рук.

## Исходники и экспорт

- [PNG-исходники](sources/m22/), [полные промпты и исправления](m22-generation-log.json).
- [Калибровка компонентов](m22-rig.json), [кадры вспомогательных листов](m22-auxiliary.json), [аудит альфы и границ](m22-source-audit.json).
- [Манифест](manifest.json): принятые элементы имеют `source`, `anchors`, `runtimeReady` и запись технического визуального просмотра. `runtimeScopes.M22` отделяет поставку этой вехи от полного плана окружения других биомов.
- Runtime WebP находятся в `client/public/mechs`; таблицы креплений и состояний — `client/src/mech/artCatalog.json` и `auxCatalog.json`.

Детали используют восемь направлений N/NE/E/SE/S/SW/W/NW, анатомические стороны оружия и общую опору 512×512. Статические компоненты размещены в сетке 4×2; движение — 8×4 (строка фазы, столбец направления). Разрушенные плечи и остановленные шасси имеют по восемь кадров, остовы и объекты — одиночные кадры. Углы, окончания и трубы имеют четыре поворота. Растровые исходники не перерисовываются скриптами: инструменты измеряют, нарезают и упаковывают.

## Интеграция

В бою и мастерской используется одна сборка компонентов. При разрушении руки появляется соответствующее плечо; при потере шасси — неподвижный повреждённый узел; при гибели — остов нужного корпуса. Перемещение проигрывает четыре фазы шага или гусениц. Генератор и тягач используют отдельные целые и разрушенные изображения. Базовые тайлы пустынной карты заменены новыми PNG-источниками; расширенные архитектурные модули экспортированы для дальнейшего наполнения карт.

Стенд `?demo=mech-art` использует настоящий Pixi renderer. Можно выбрать размер 64/96/128 и целую сборку, движение, повреждённые руки/шасси или остов. Четыре сборки одновременно показаны в восьми направлениях.

```powershell
python tools/mech-production.py --stage
python tools/mech-art-review.py
# После визуального просмотра исходников и контактных листов:
python tools/mech-production.py --accept-reviewed
python tools/mech-catalog.py --require-complete
python tools/mech-catalog.py --check --require-complete
npm --prefix client test
npm --prefix client run build
# При запущенном vite preview:
node tools/mech-art-browser-check.mjs http://127.0.0.1:5063
```

Контактные листы и браузерные снимки сохраняются в `.artifacts/m22-art`. Браузерная матрица охватывает 672 состояния сборок (4×8×3×7); отдельные тесты проверяют выбор оружия, плеч, остановленного шасси, фаз движения, остова и объектов. Это техническая приёмка. Сквозной плейтест человеком и проверка на физическом телефоне отмечаются отдельно в [отчёте M22](../../../docs/playtest/M22.md).

Глобальный `runtimeReady` полного производственного плана остаётся `false`: окружение иных биомов, весь расширенный набор архитектуры и последующая оптимизация атласов не входят в обязательный комплект M22.
