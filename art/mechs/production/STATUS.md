## Проверки

В headless Chrome отрисованы 32 состояния: восемь направлений × целый / без правой / без левой / без обеих рук. Во всех состояниях спрайт непустой и не касается границ кадра; скрытие каждой руки меняет изображение. Целая сборка и вариант без рук визуально просмотрены; редактор загружается без ошибок. Проверен синтаксис JavaScript.

Повторение проверки из корня репозитория:

```powershell
node art/mechs/production/audit.mjs
node art/mechs/production/build-rig.mjs
node art/mechs/production/browser-check.mjs rig-review.html healthy
node art/mechs/production/browser-check.mjs rig-review.html nogun
node art/mechs/production/browser-check.mjs rig-review.html noshield
node art/mechs/production/browser-check.mjs rig-review.html noarms
node art/mechs/production/verify-rig.mjs
```

Браузерная проверка использует установленный Google Chrome, изолированный профиль и временный локальный HTTP-сервер. verify-rig.mjs проверяет результаты последнего браузерного прогона; после изменения PNG или rig нужно повторять четыре сценария.

Аудит пяти активных источников: ошибок декодирования, отсутствующей альфы и пустых ячеек нет. Исходные листы 1774×887; прямоугольники 443/444 px берутся из аудита и приводятся к координатам 512×512 при отрисовке. PNG не изменялись программно. Упаковка унифицированного атласа остаётся этапом P6.
